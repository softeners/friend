# ДРУГ — лендинг проекта

Статичный одностраничник. Без сборщиков, без фреймворков, без зависимостей —
открывается двойным кликом по `index.html`.

## Структура

```
index.html          — вся разметка, разбита на блоки комментариями
css/reset.css       — базовый сброс
css/style.css       — дизайн-система (переменные) + все компоненты
js/main.js          — 11 независимых модулей (меню, табы, аккордеон, счётчики…)
assets/img/         — картинки: logo.png, hero.jpg, region-1..6.jpg, person-1..2.jpg
assets/fonts/       — шрифты (если подключаем локально)
assets/icons/       — svg-иконки
assets/video/       — видео
материалы/          — исходники от заказчика
реф/                — референс дизайна
```

## Как менять

**Цвета, шрифты, отступы** — только в `:root` в начале [css/style.css](css/style.css).
Меняешь одну переменную — меняется весь сайт.

| Переменная | Что это |
|---|---|
| `--bg`, `--bg-2`, `--surface` | фоны |
| `--accent` | оранжевый акцент |
| `--text`, `--text-dim`, `--text-mute` | три уровня текста |
| `--section-y` | вертикальные отступы секций |
| `--container` | максимальная ширина контента |

**Секции** — в `index.html` каждая обёрнута комментарием вида
`<!-- ───── ПРОБЛЕМА ───── -->`. Порядок можно менять перетаскиванием блока,
ничего не сломается.

## Готовые компоненты

- `.card` / `.card--accent` — карточка, оранжевая карточка
- `.grid--2 … --5` — сетки, сами схлопываются на мобилке
- `[data-tabs]` — табы (кнопка `data-tab="id"` → панель с этим `id`)
- `[data-accordion]` — аккордеон
- `[data-regions]` — список регионов со сменой фото по наведению
- `[data-count="30"]` — цифра, которая анимированно набегает при появлении
- `.budget__bar span[style="--w:82%"]` — полоса диаграммы
- `.reveal` — навешивается скриптом автоматически на все секции и карточки

## Что осталось положить

1. `assets/img/hero.jpg` — фон первого экрана
2. `assets/img/og.jpg` — картинка для соцсетей, 1200×630

   кладём в `assets/fonts/` и подключаем `@font-face` в начале `style.css`
